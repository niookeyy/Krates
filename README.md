# Krates

> Named after Socrates — an AI debate partner that questions you instead of just agreeing with you.

Most chatbots are optimized to be agreeable. Krates does the opposite: it's built to challenge your reasoning, spot weak or unsupported claims, and ask the one question that helps you find the flaw in your own argument — before offering its own view.

## Why I built this

I wanted a thinking partner for brainstorming, exploring philosophy, and debating hard topics (morality, politics, humanity) — the kind of conversations that are genuinely useful when you have an opinion but no one around to stress-test it with. Existing assistants are too quick to validate whatever you say. Krates is designed to push back first, and only agree when your reasoning actually holds up.

## How it works

Krates uses a **hybrid detection pipeline**, not just a single LLM call:

1. **Zero-shot classification** (Hugging Face `transformers`, `facebook/bart-large-mnli`) scores whether a statement "considers context and reasoning" or "concludes without evidence or context."
2. **Rule-based generalization check** — a keyword pass for absolute language (`semua`, `selalu`, `tidak pernah`, `pasti`, etc.) that catches weak arguments the ML model is under-confident about.
3. Based on both signals, Krates builds a different instruction for the LLM:
   - **Weak/generalized argument** → the LLM asks *one* Socratic question meant to expose the gap, instead of correcting directly.
   - **Well-reasoned argument** → the LLM deepens the debate from an angle the user hasn't considered yet.
4. The final response is generated by a **locally-run LLM** (Llama 3.2 via [Ollama](https://ollama.com)) using a custom `Modelfile` that defines Krates' persona and debate principles — nothing is sent to a third-party API.

### Why hybrid instead of just the ML model?

In testing, the zero-shot classifier alone was inconsistent on borderline cases — e.g. it scored *"Semua Politisi itu Korup"* as "considers context" at only 58% confidence, when it's clearly a generalization. Adding the keyword-based generalization check as a second signal catches cases like this that the ML model alone misses or is under-confident about, making the overall detection more reliable.

## Krates' principles (from the Modelfile)

- **Humanity** — respects the person, never assumes bad faith, admits when it's wrong or doesn't know.
- **Responsibility** — won't make decisions for you; its job is to help you think more clearly, not think for you.
- **Universal morality** — believes people already carry a moral sense, even when they act against it.
- **Truth must be questionable** — anything immune to questioning is treated as dogma, not truth, including Krates' own statements.
- **Debate style** — asks before correcting; corrects firmly only when something crucial is wrong; otherwise asks the question that lets you get there yourself.

## Tech stack

- Python
- Hugging Face `transformers` (zero-shot classification)
- Ollama (local LLM runtime) + Llama 3.2
- Custom Modelfile for persona/system prompt design

## Setup

1. Install [Ollama](https://ollama.com) and pull a base model:
   ```bash
   ollama pull llama3.2
   ```
2. Build the Krates model from the included Modelfile:
   ```bash
   ollama create krates -f Modelfile
   ```
3. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run Krates:
   ```bash
   python main.py
   ```
